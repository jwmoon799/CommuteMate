CommuteMate 연동 3D 주행

이 버전은 HTML 파일을 직접 여는 방식 대신 로컬 연동 실행기로 엽니다.
1. Pleos 에뮬레이터 및 CommuteMate를 켜둡니다. 앱은 P상태 유지.
2. 이전에 file:// 로 열었던 독립3D 창은 닫습니다.
3. 터미널: python3 "/Users/munjeong-u/Documents/Codex/2026-11-12/users-munjeong-u-documents-codex-2026/outputs/CommuteMate_연동3D_실행.py"
4. http://127.0.0.1:8091/ 에서 ‘차량 신호 연결됨’ 표시 확인.
5. 앱에서 브리핑 또는 영어학습 재생. 3D의 좌회전/우회전 또는 기존콘솔 깜빡이 조작.
6. 실제에뮬레이터신호ON → 앱 SDK가일시정지, 3D차선정렬2초/코너접근3초/90도회전4초 → 실제OFF요청 → 실제OFF수신에따라학습재개.

기본규칙
- 1차선(왼쪽)좌회전: 차선유지. 우회전:2차선이동후우회전.
- 2차선(오른쪽)우회전: 차선유지. 좌회전:1차선이동후좌회전.
- 신호없음:현재차선직진. 최초1차선.
- 회전완료시선택해제. 내부적으로가짜OFF처리하지않음.
- 사용자일시정지는기존앱규칙대로유지. 도착후학습재개없음.
- 연결끊김/신호변경시낡은회전완료로신호끄지않음. 실제OFF미확인시자동학습재개로간주하지않음.
- 앱의코루틴/플레이어를새타이머로교체하지않음. 기존Vehicle SDK실제신호구독사용.

구현소스
CommuteMate/tools/drive_bridge.py: 콘솔 실제 /vehicle/state 및 /vehicle/turn-signal API 연결.
CommuteMate/tools/driving_demo/turn-route.js: 차선/경로/90도회전/완료상태.
CommuteMate/tools/driving_demo/index.html:3D렌더/실제신호조회/회전완료통보.
Android MainActivity.kt:기존 Vehicle 구독/일시정지재개, 이번에실제신호진단로그추가.

연결은같은Mac의127.0.0.1에만바인딩. 일반웹사이트의변경요청은Origin/사용자정의헤더로거절.
제어하는것은Pleos에뮬레이터방향지시등뿐. 실제차량깜빡이제어/기어/속도변경안함.
화면의가상속도는에뮬레이터속도와분리. 앱의주행중화면제한은여전히미해결.

확인상태
- 차선4조합/연속경로/90도/완료1회/실제OFF대기/직진 단위검사통과.
- 이른완료/오래된요청/중복완료/신호대체/연결끊김/재연결 무효화 검사통과.
- 실제로컬브라우저: 좌회전→자동OFF,1→2차선이동→우회전→자동OFF 확인.
- 콘솔상실제신호값Off확인. Origin없는POST는403확인.
- 앱학습중정지/복귀는사용자최종확인필요. 2차선좌회전과2차선우회전의브라우저실기추가확인필요.
